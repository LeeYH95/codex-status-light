# 5 小时悬浮额度球设计

## 目标

将折叠态红绿灯下方的小悬浮额度球从“周额度剩余”改为“5 小时额度剩余”，使其与用户最即时的额度约束一致。

## 行为

- 液面高度、绿/黄/红/未知颜色、中央百分比与辅助功能文本均读取 `CodexQuota.fiveHourRemainingPercent`。
- `fiveHourRemainingPercent` 缺失时，球保持现有未知样式并显示 `--`；绝不回退显示 `weeklyRemainingPercent`。
- 展开面板中 5 小时与 1 周额度的展示、周重置卡、数据解析和刷新逻辑不变。

## 代码边界与验证

- 仅修改折叠额度球 View 的数据绑定与其名称/辅助功能文案。
- 在自测中新增一个纯展示选择器，明确悬浮球应选用 5 小时额度，同时覆盖 5 小时缺失时返回 `nil` 的边界；这使展示规则可测试，而不是依赖 SwiftUI 私有 View。
- 运行 self-test、Swift build 与 `git diff --check`。
- 按用户授权的小改动例外，不使用测试 app；正式 app 仅在合并至 `main` 后、用户明确要求生成时更新。
